Result and limitations

Completed Blender-to-Seedance 2.5 workflow. Sampled visual review found the approved amber-glass bottle, gold cap and ivory label in a dry dune setting, with four camera shots and a readable final hero label. A second edit removed an unwanted distant ocean strip. The generated film approximates the guide: it does not certify exact 3D geometry, camera azimuth, object count or pixel-perfect identity across every frame. Fine text is softer in distant shots. The editable Blender file contains the greybox guide, not the photoreal generated world.
